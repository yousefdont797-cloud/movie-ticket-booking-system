INTRODUCTION

The Movie Ticket Booking System is a simple C++ project designed to make the process of booking movie tickets easier. The system allows users to enter the movie name, ticket price, customer name, and number of tickets. It calculates the total price and displays the booking details

_______________________________________________________________________________________________________________________________________________________________________________
FEATURES

1-allow the user to enter the movie name
2-Stores the customer's name and number of tickets
3-Allows users to calculate the price after applying a discount
4-Calculates the total price based on the number of tickets
5-Displays the movie name, customer name, ticket price, number of tickets, and total cost

PURPOSE OF THE PROGRAM

The purpose of the Movie Ticket Booking System is to create a simple program that allows users to book movie tickets easily. It helps users enter movie and customer information, select the number of tickets, and calculate the total price with or without a discount.
